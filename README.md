## Development
Node.js 22; npm install; npm run dev. Run npm test, npm run lint, npm run typecheck and npm run build before release. Generate and commit npm lockfile once registry access is available. See DEVELOPMENT_STATUS.md for verified state.

This is an early development preview, not a launched agency or a working CRM. No production credentials, pricing, invented contact details or case studies. Keep external demo databases and deployments isolated. Never publish private admin access.
