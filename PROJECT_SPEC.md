# Project specification
Shuvi 360, Indore, English primary/Hindi secondary, INR, Asia/Kolkata. First priority: client acquisition, not advanced management. Nine services are defined in src/lib/services.ts. Public website, service detail pages, portfolio and demo center, video samples, actual case studies, consultation and contact, then secure agency operations.

Public routes /, /about, /services/[slug], /portfolio, /demos, /case-studies, /contact, /consultation, /pricing, /privacy, /terms and /lp/[slug]. Protected /admin, /client, /creator.
